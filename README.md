# CityFlow — Intelligent Adaptive Traffic Management

🚀 **Live Demo:** [https://city-flow-rl-vercel.vercel.app/](https://city-flow-rl-vercel.vercel.app/)

CityFlow is an intelligent adaptive traffic management system that uses an RL-based traffic controller to dynamically manage traffic signals based on traffic conditions.

## Features

- 🚦 Adaptive traffic signal control
- 🚗 Real-time traffic simulation
- 🤖 RL-based decision engine
- 📊 Queue, waiting-time, congestion and throughput metrics
- 🚑 Emergency vehicle priority
- 🛣️ Safe lane-based vehicle movement
- 🔴 Automatic traffic stopping during emergency mode

**Live Demo:** [CityFlow Web Application](https://city-flow-rl-vercel.vercel.app/)
